# 🚀 Personal Portfolio Website

A responsive and modern personal portfolio website to showcase my projects, skills, experience, and achievements.

## 🔗 Live Demo
👉 https://pramod-gg.github.io/portfolio/

---

## 📌 Features

- 🏠 Home section with profile and introduction
- 👨‍💻 About section with background details
- 🎓 Education and Experience sections
- 💼 Projects showcase with descriptions and links
- 🏆 Achievements section
- 📞 Contact form (email integration using FormSubmit)
- 🌙 Dark mode toggle
- ✨ Animated UI and modern design

---

## 🛠 Tech Stack

- HTML5  
- CSS3 (Flexbox, Animations)  
- JavaScript (DOM Manipulation, Events)
